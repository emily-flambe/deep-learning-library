Chapter 1: The Tensor Class

What is a Tensor, and why do we need one?

A numpy array is just data—numbers sitting in memory.

A Tensor is a wrapper around a numpy array that also remembers:

  • Where did this data come from?
  • What math operation created it?
  • Should we track gradients for backpropagation?

Think of it like a package vs. a tracked package. A numpy array is the item. A Tensor is the item plus shipping history.

Exercise 1: The __init__ method

The Problem

Users will create Tensors in different ways:

Tensor([1, 2, 3])                    # from a Python list
Tensor(5)                            # from a single number
Tensor(np.array([1, 2, 3]))          # from a numpy array
Tensor(some_existing_tensor)         # from another Tensor

Your job: make all of these work. Internally, self.data should always end up as a numpy array.

Why?

The rest of your library assumes self.data is a numpy array. If it's sometimes a list, sometimes a Tensor, sometimes an array—everything breaks. So __init__ normalizes the input.

Thinking Through It

Ask yourself:

  1. If someone passes a Tensor, how do I get the numpy array out of it?
  2. If someone passes a numpy array, what do I need to do? (Trick question—maybe nothing?)
  3. If someone passes a list or number, how do I convert it to a numpy array?

Exercise 3: numpy() and detach()

numpy()

Returns a plain numpy array, disconnected from the Tensor.

t = Tensor([1, 2, 3])
arr = t.numpy()  # Just the raw numbers, no Tensor wrapper

Why return a copy? So that modifying arr doesn't accidentally change t.data.

detach()

Returns a new Tensor with the same data, but requires_grad=False.

t = Tensor([1, 2, 3], requires_grad=True)
t2 = t.detach()  # Same numbers, but won't track gradients

Why? Sometimes you want to use a tensor's values without including it in the computation graph.

What are _op and _inputs for?

You won't use these yet, but here's the idea:

a = Tensor([1, 2])
b = Tensor([3, 4])
c = a + b  # c.data = [4, 6]

When you implement addition later:

  • c._op will be "add" (or some operation object)
  • c._inputs will be [a, b]

This is how the tensor "remembers its history" for backpropagation. For now, just initialize them as None and [].
