Chapter 2: Tensor

2.1 Tensor Fundamentals

Arrays

An array is a collection of elements identified by indices or keys. Arrays are implemented through NumPy's high-performance N-dimensional array object.

NumPy Arrays

NumPy arrays provide fixed memory blocks, vectorized operations, and exceptional speed. They serve as the raw material that tensors wrap.

Tensors

A tensor is more than just a multi-dimensional array; it is a container for data that remembers its own history. Tensors hold arrays in a structured way, enabling efficient operations and computation graph tracking.

Tensor Properties

A tensor instance tracks:

  • data: NumPy array containing values
  • dtype: Data type (default: float32)
  • grad: Gradients from backpropagation
  • requires_grad: Boolean enabling/disabling gradient tracking
  • _op: Mathematical operation that created this tensor
  • _inputs: Input tensors used in creation

Computation Graph

A directed graph representing:

  • Tensor values as nodes
  • Operations as connecting edges
  • Data flow from inputs through operations to outputs

2.2 Data Operations

String Representations

def __repr__(self):
    """
    Detailed representation showing data and gradient tracking.
    Example:
        >>> x = Tensor([1, 2, 3])
        >>> print(repr(x))
        Tensor([1. 2. 3.], requires_grad=True)
    """
    return f"Tensor({self.data}, requires_grad={self.requires_grad})"

def __str__(self):
    """
    Simple string representation (just the data).
    Example:
        >>> x = Tensor([1, 2, 3])
        >>> print(x)
        [1. 2. 3.]
    """
    return str(self.data)

Basic Properties

@property
def shape(self):
    return self.data.shape

@property
def dtype(self):
    return self.data.dtype

@property
def ndim(self):
    return self.data.ndim

@property
def size(self):
    return self.data.size

@property
def device(self):
    return self._device

Methods

numpy(): Extracts raw NumPy data, returning a copy disconnected from the computation graph.

detach(): Creates a new Tensor with identical data but requires_grad=False, excluding it from gradient computation during backpropagation.

Both methods are essential for inspection and manipulation without affecting the computational graph.
